# toolkit

Консольный набор утилит, который включает калькулятор арифметических выражений и конвертер единиц измерения.

# Установка

Для установки зависимостей проекта используйте:

```text
pip install poetry
```

После этого Poetry создаст виртуальное окружение для проекта.

Для активации виртуального окружения используйте:

```text
poetry env activate
```

После активации виртуального окружения программу можно запускать с помощью обычной команды `python`.

# Использование

Для вычисления выражения:

```text
python -m toolkit calc "EXPRESSION"
```

Например:

```text
python -m toolkit calc "10 + 8 * 2"
```

Для конвертации из одной единицы измерения в другую:

```text
python -m toolkit convert VALUE --from UNIT --to UNIT
```

Например:

```text
python -m toolkit convert 100 --from cm --to m
```

Для получения справки:

```text
python -m toolkit --help
```

# Поддерживаемые единицы

Длина:

`mm`, `cm`, `m`, `km`

Масса:

`g`, `kg`

Температура:

`c`, `f`, `k`

Регистр единиц измерения не имеет значения.
